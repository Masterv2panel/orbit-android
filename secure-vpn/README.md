# Orbit Secure (Android)

این زیرپروژه از اپ ORBIT محاسبهٔ ترکیب بدن مستقل است؛ صفحهٔ وب و workflow قدیمی ORBIT دست‌نخورده می‌ماند. اپ Flutter از `sing-box` برای Hysteria2 و Android System WebView برای وب‌گردی استفاده می‌کند.

## مرورگر

- چند زبانهٔ هم‌زمان با نوار نشانی و جست‌وجو، عقب/جلو، توقف/بارگذاری دوباره، خانه، شمارنده و مدیریت زبانه‌ها.
- JavaScript، DOM Storage و Web SQL فعال‌اند. Safe Browsing و کنترل‌های zoom نیز در صورت پشتیبانی WebView فعال‌اند. User-Agent پیش‌فرض Android WebView دست‌کاری نمی‌شود.
- تاریخچه تا ۵۰۰ بازدید اخیر و نشانک‌ها در فضای خصوصی برنامه روی دستگاه ذخیره می‌شوند. همگام‌سازی ابری ندارند؛ workflow ساخت APK، Android Auto Backup را برای برنامه غیرفعال می‌کند. دادهٔ Preferences رمزگذاری‌شده فرض نشود.
- صفحهٔ کتابخانه دو بخش جدا برای تاریخچه و نشانک دارد؛ می‌توانی موردها را یکی‌یکی یا هر بخش را کامل پاک کنی. منوی مرورگر همچنین کوکی‌ها، cache و Web Storage سایت‌ها را جداگانه پاک می‌کند.
- درخواست‌های مجوز وب، از جمله geolocation و camera/microphone، رد می‌شوند. دسترسی file/content خاموش است و کوکی شخص ثالث به‌طور پیش‌فرض بسته است؛ کاربر می‌تواند آن را با تأیید روشن کند، اما برخی سایت‌ها ممکن است به‌خاطر محدودیت پیش‌فرض درست کار نکنند.
- دانلودهای درخواست‌شده توسط صفحه با یک پنجرهٔ راهنما نشان داده می‌شوند و لینک دانلود در clipboard کپی می‌شود تا در دانلودمنیجر دستگاه باز شود؛ این نسخه هنوز دانلود پس‌زمینه‌ای و کتابخانهٔ فایل داخل برنامه ندارد.

## Hysteria2 و حفاظت شبکه

- لینک‌های `hysteria2://` و `hy2://` وارد می‌شوند. SNI و Salamander پشتیبانی می‌شوند؛ رمز پروفایل فقط هنگام اجرا نگه‌داری می‌شود.
- `insecure=1` پذیرفته می‌شود، اما پیش از اتصال هشدار و تأیید صریح می‌خواهد. در این حالت گواهی TLS اعتبارسنجی نمی‌شود و خطر حملهٔ واسطه وجود دارد.
- TUN با مسیر پیش‌فرض و `strict_route` فعال است. DNS روی UDP به 1.1.1.1 فرستاده می‌شود و تنظیم `detour: proxy` آن را از outbound پروکسی عبور می‌دهد؛ این DNS-over-HTTPS نیست و resolver محتوا را می‌بیند.
- مرورگر پیش از اتصال VPN سایت باز نمی‌کند. در قطع اتصال، WebViewهای باز متوقف و از رابط حذف می‌شوند؛ این رفتار kill switch سراسری سیستم نیست. برای قفل همهٔ برنامه‌ها در Android، گزینه‌های **Always-on VPN** و **Block connections without VPN** را دستی فعال کن.
- سنجش تأخیر یک درخواست HTTPS 204 از مسیر شبکه پس از اتصال است؛ ICMP ping یا سنجش مستقیم handshake سرور نیست.

## هماهنگ‌سازی timezone

پس از اتصال VPN، اپ پیش از نخستین درخواست از کاربر اجازه می‌گیرد؛ lookup به‌طور پیش‌فرض خاموش است. فقط پس از فعال‌سازی، با درخواست HTTPS به `ipapi.co/timezone` منطقهٔ زمانی IANA خوانده می‌شود. این سرویس بیرونی IP درخواست‌کننده را دریافت می‌کند؛ در تونل سالم انتظار می‌رود IP خروجی VPN را ببیند. می‌توانی این گزینه را از منوی مرورگر تغییر دهی. خطای سرویس، محدودیت نرخ یا قطع تونل می‌تواند lookup را ناموفق کند.

timezone فقط با یک UserScript در JavaScript صفحه تنظیم می‌شود و ساعت یا timezone Android تغییر نمی‌کند. اسکریپت APIهای رایج `Intl.DateTimeFormat` و `Date` را هدف می‌گیرد، اما یک timezone واقعی برای فرایند WebView یا تغییر کامل fingerprint نیست. تزریق در document-start به قابلیت Android System WebView وابسته است؛ در نسخه‌هایی که این قابلیت را ندارند، تزریق ممکن است دیر برسد و سایت پیش‌تر timezone دستگاه را خوانده باشد. برنامه موفقیت این تطبیق را تضمین نمی‌کند.

## محدودیت‌های امنیتی

WebView از نسخهٔ نصب‌شدهٔ Android System WebView استفاده می‌کند؛ آن را از فروشگاه دستگاه به‌روز نگه دار. WebRTC به‌طور کامل خاموش نشده است. مسیریابی UDP از TUN و فیلتر مجوزها تضمین مستقل علیه همهٔ انواع نشت نیست؛ روی گوشی و شبکهٔ واقعی آزمایش کن.

Orbit fingerprint را حذف نمی‌کند، IP مسکونی جعل نمی‌کند و ناشناس‌بودن کامل یا «بدون نشت» را تضمین نمی‌کند. نوع IP خروجی به ارائه‌دهندهٔ VPN وابسته است. HTTP غیررمزشده نیز همچنان ممکن است باز شود؛ برای محتوای حساس از HTTPS استفاده کن.

## ساخت APK

GitHub Actions فایل‌های release را به تفکیک معماری در Artifact با نام `orbit-secure-android-release-apks` بارگذاری می‌کند. برای بیشتر گوشی‌های جدید، `app-arm64-v8a-release.apk` مناسب است. این بیلد برای آزمایش با کلید debug امضا می‌شود؛ انتشار عمومی به کلید release و رعایت تعهدات GPL-3.0-or-later نیاز دارد.
