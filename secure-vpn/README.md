# Orbit Secure (Android)

این زیرپروژه مستقل از اپ ORBIT محاسبهٔ ترکیب بدن است؛ صفحهٔ وب و workflow قدیمی ORBIT دست‌نخورده می‌مانند. این فاز یک کلاینت اندرویدی Hysteria2 است و از موتور `sing-box` از طریق `sing_box_flutter` استفاده می‌کند.

## پیاده‌سازی فاز اتصال

- ورود لینک `hysteria2://` یا `hy2://`، بررسی فیلدهای لازم و نمایش میزبان بدون نمایش رمز.
- ساخت outbound از نوع Hysteria2 با بررسی گواهی TLS اجباری، پشتیبانی از SNI و Salamander.
- TUN اندرویدی با مسیر پیش‌فرض از طریق پروکسی و resolver DNS هدایت‌شده از طریق همان outbound.
- درخواست رضایت VPN از خود Android، foreground notification و نمایش وضعیت اتصالِ گزارش‌شده از هسته.
- تنظیمات اتصال در اپ خودمان روی دیسک ذخیره نمی‌شوند و Intent اندروید نیز حاوی رمز نیست؛ جزئیات پروفایل در طول کار به هستهٔ native داده می‌شود.
- تست‌های واحد برای URI، رد TLS ناامن و ساخت JSON؛ Workflow بیلد مستقل و خروجی APK جداگانه.

## ساخت APK

در GitHub Actions، workflow با نام **Build Orbit Secure Android APK** را اجرا کن. فایل نصب‌پذیر `app-debug.apk` در Artifact با نام `orbit-secure-android-apk` قرار می‌گیرد. این APK با کلید debug امضا می‌شود و برای نصب/آزمایش است؛ برای انتشار عمومی باید فرایند امضای release جداگانه تنظیم شود.

## محدودیت‌ها و احتیاط‌ها

مرورگر داخلی هنوز در این فاز اضافه نشده است. بیلد موفق فقط کامپایل برنامه را نشان می‌دهد؛ اتصال شبکه را باید روی گوشی واقعی با سرور و لینک Hysteria2 معتبر آزمایش کرد. لینک یا رمز سرور را در GitHub یا log قرار نده.

این برنامه ادعای ناشناس‌بودن کامل یا «بدون نشت» ندارد. Android **Always-on VPN / Block connections without VPN** می‌تواند برای fail-closed پیکربندی شود، اما باید روی دستگاه و شبکهٔ واقعی آزمایش شود. fingerprint مرورگر و سازگارکردن ساعت/مکان نیز خارج از دامنهٔ این فاز است.
