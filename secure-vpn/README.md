# Orbit Secure (Android)

این زیرپروژه مستقل از اپ ORBIT محاسبهٔ ترکیب بدن است؛ صفحهٔ وب و workflow قدیمی ORBIT دست‌نخورده می‌مانند. اپ از `sing-box` برای VPN مبتنی بر Hysteria2 و Android WebView برای مرور خصوصی استفاده می‌کند.

## قابلیت‌های فعلی

- مرورگر داخلی با آدرس/جست‌وجو، عقب/جلو، بارگذاری مجدد و صفحهٔ خانه؛ سابقه و نشانک در برنامه ذخیره نمی‌شوند.
- مجوز مکان، دوربین، میکروفون و دسترسی‌های وب رد می‌شوند؛ کوکی شخص ثالث و دسترسی file/content برای WebView خاموش است. کوکی، cache و local storage هنگام شروع/پاک‌سازی نشست پاک می‌شوند.
- مرورگر تا اتصال VPN بارگذاری وب را مسدود می‌کند و پس از قطع تونل صفحه را پاک می‌کند. این قفل فقط مرورگر برنامه را پوشش می‌دهد.
- ورود لینک `hysteria2://` یا `hy2://`، بررسی فیلدهای لازم و نمایش میزبان بدون نمایش رمز.
- ساخت outbound Hysteria2 با SNI و Salamander. پارامتر `insecure=1` پذیرفته می‌شود، اما پیش از اتصال هشدار می‌دهد و تأیید صریح می‌خواهد؛ در این حالت گواهی TLS اعتبارسنجی نمی‌شود و اتصال در برابر حملهٔ واسطه آسیب‌پذیر است.
- TUN اندرویدی با مسیر پیش‌فرض از طریق پروکسی و DNS هدایت‌شده از طریق همان outbound.
- سنجش زمان پاسخ HTTPS از داخل تونل پس از اتصال؛ این ICMP ping به خود سرور نیست و به endpoint آزمایش وابسته است.
- تنظیمات پروفایل روی دیسک ذخیره نمی‌شوند و Intent اندروید حاوی رمز نیست؛ جزئیات پروفایل فقط هنگام اتصال به هستهٔ native داده می‌شود.

## Kill switch

برای قفل‌کردن کل دستگاه، در تنظیمات Android برای Orbit Secure گزینه‌های **Always-on VPN** و **Block connections without VPN** را فعال کن. اپ به‌تنهایی نمی‌تواند این گزینهٔ سیستمی را بی‌اجازه روشن کند. مسیرهای IPv4/IPv6، DNS، WebRTC، قطع تونل و تغییر Wi-Fi/دیتا باید روی گوشی واقعی آزمایش شوند.

## ساخت APK

GitHub Actions فایل‌های release را به تفکیک معماری در Artifact با نام `orbit-secure-android-release-apks` بارگذاری می‌کند. برای بیشتر گوشی‌های جدید، `app-arm64-v8a-release.apk` مناسب است. این بیلد برای آزمایش با کلید debug امضا می‌شود؛ انتشار عمومی به کلید release و رعایت تعهدات GPL-3.0-or-later نیاز دارد.

## محدودیت‌ها و احتیاط‌ها

مرورگر بر پایهٔ WebView سیستمی Android است؛ حذف کامل fingerprint یا شبیه‌سازی قابل‌اعتماد یک کاربر خانگی ممکن نیست. WebRTC در موتور WebView به‌طور اختصاصی غیرفعال نشده است؛ تا وقتی تونل فعال است، ترافیک UDP باید از TUN عبور کند، اما این جایگزین فعال‌کردن قفل سیستمی و آزمون روی گوشی نیست. timezone با ساعت گوشی می‌ماند؛ درخواست مکان وب رد می‌شود و مکان مبتنی بر IP تابع خروجی VPN است. IP دیتاسنتری VPN با تغییر User-Agent یا ساعت به IP خانگی تبدیل نمی‌شود. این برنامه ناشناس‌بودن کامل یا «بدون نشت» را تضمین نمی‌کند. اتصال واقعی Hysteria2 و آزمایش نشت شبکه نیازمند گوشی، سرور و لینک معتبر است. لینک یا رمز سرور را در GitHub یا log قرار نده.
